Send turn to agent under test agent_adapter.py

turn_input — the question on turn 0, or the driver's retry feedback on turns 1–2 — is POSTed to math-solver-agent's /api/query. Transient 5xx / 429 / network errors are retried up to 3× with backoff (retry.py), separately from this conversation-level loop.

Marking marking.py

Deterministic. score_answer() reads the section's rubric (single ±, multi ±/partial, numeric, match) and returns points / max_points / answered.

Judge step_validator.py

A separate LLM call. validate_steps() asks a judge provider whether the response shows real working, and whether that working is internally sound — independent of answer correctness.

scorer.py → JEEConversationScorer.score()

Weighted turn score
answer_fraction = clamp(points / max_points, 0, 1) steps_fraction = 1.0 valid · 0.5 shown-but-invalid · 0.0 missing value = 0.7 × answer_fraction + 0.3 × steps_fraction passed = full_marks and steps_valid
Accumulator.update() accumulator.py

State is replaced by this turn's score, not merged with it — earlier turns are fully discarded. Only whichever turn runs last will ever be reported.
